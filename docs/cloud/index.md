# Cloud

I hold associate-level certifications on all three major clouds. These pages map the core services
side by side and collect the patterns I use most.

## Service map

| Need | AWS | Azure | GCP |
|---|---|---|---|
| Virtual machines | EC2 | Virtual Machines | Compute Engine |
| Managed Kubernetes | EKS | AKS | GKE |
| Serverless functions | Lambda | Functions | Cloud Run functions |
| Object storage | S3 | Blob Storage | Cloud Storage |
| Managed relational DB | RDS / Aurora | Azure SQL / Database for PostgreSQL | Cloud SQL |
| Virtual network | VPC | Virtual Network (VNet) | VPC |
| Identity & access | IAM | Microsoft Entra ID + Azure RBAC | Cloud IAM |
| Monitoring | CloudWatch | Azure Monitor | Cloud Monitoring |
| Infrastructure as code (native) | CloudFormation | Bicep / ARM templates | Infrastructure Manager |
