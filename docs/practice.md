# Practice

Flashcards built from every question in the [interview prep](interview-prep/index.md) section. Pick a deck, answer **out loud** before you reveal, then be honest: *I knew it* counts towards your progress, *Review again* puts the card in your review pile.

<div id="sb-practice">
  <noscript>Practice mode needs JavaScript. You can still read every question in <a href="../interview-prep/">Interview prep</a>.</noscript>
</div>

!!! tip "A good answer has four parts"
    **Mechanism** (how it works) → **steps in order** (what you'd check first, second, third) → **fix** → **prevention** (what you'd change so it can't happen again). Use the 2-minute timer to practise being concise.

Your progress is stored only in this browser. Clearing site data resets it.
